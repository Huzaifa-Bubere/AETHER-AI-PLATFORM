# 09 — Resume Builder (ATS-friendly, selectable-text PDF)

**Feature:** A real resume builder — structured section editor, live text-based
PDF preview, five ATS-safe templates, resume versions with autosave, deterministic
ATS feedback and a downloadable PDF with a dynamic filename.

**Scope:** the Resume **Analyzer** (`/resume`, upload + AI feedback) is unchanged
and covered in `08-resume-analyzer.md`. This document covers `/resume-builder`.

**Entry point:** `/resume-builder`.

**Guardrails to keep verifying:**
- The PDF is generated by `@react-pdf/renderer` — real selectable text, **not** a
  canvas screenshot or PNG-in-PDF.
- No letter-spacing in the PDF templates (per-character offsets break text
  extraction, e.g. `E D U C AT I O N`).
- No raster images anywhere in the export (`/Subtype /Image` never appears).
- No decorative infographic layout: single column, plain headings, standard
  bullets. AETHER ATS Classic is the default and recommended template.
- The ATS score is computed server-side from structured content — never by AI.

## 2. Templates (spec §18–§19)

Five PDF templates, all single column and text-only:

| Template id | Purpose |
| --- | --- |
| `ats-classic` | **Default / recommended.** Name + contact header, ruled uppercase headings, compact one-page layout (reference-style) |
| `graduate-fresher` | Education and projects before experience |

| `technical-professional` | Skills-forward, compact technology lines |

### Fixes this test forced

| Symptom | Root cause | Fix |
| --- | --- | --- |
| Headings extracted as `E D U C AT I O N` | `letterSpacing` in the PDF styles emits per-character offsets | letter-spacing removed from every template style |
| Email read as `Engineerhuzaifa.bubere@example.com` | Modern template used a two-column header, so extractors merged the title into the contact line | Modern header is now a single left-aligned block |
| Education section empty for `B.E. Computer Engineering` | Parser degree regex only matched Bachelor/Master/B.Tech/M.Tech | Regex extended (B.E., B.Sc, BCA, MCA, B.Com, BBA, MBA, Diploma, HSC/SSC, 12th/10th …) plus institution and CGPA extraction |

## 4. Dynamic filename (spec §22)

`buildResumeFilename(name, title)` → `Huzaifa_Bubere_Software_Engineer_Resume.pdf`.
Accents are stripped, separators normalized, and the segment list degrades
gracefully (`AETHER_Resume.pdf` when only one part exists). No hardcoded name.

## 5. Versions, autosave, set default (spec §25–§26)

**API surface**

| Call | Behaviour |
| --- | --- |
| `GET /api/resume/versions` | List, newest first |
| `POST /api/resume/versions` | Create; the **first** version is automatically the default; plan limits enforced (`402 UPGRADE_REQUIRED`) |
| `PUT /api/resume/versions/:id` | Autosave; recomputes ATS server-side; `isDefault: true` clears the flag on sibling versions |
| `POST /api/resume/versions/:id/default` | Promote explicitly |
| `DELETE /api/resume/versions/:id` | Delete; if the default was deleted the newest survivor is promoted |
| `POST /api/resume/versions/from-uploaded` | Seed a version from the last analyzed upload |

**UI:** the page autosaves on a 1.1 s debounce after edits and shows
`Unsaved changes → Saving… → Saved · <time>` (or `Save failed`). The version bar
supports create, rename (inline), duplicate, set default (★) and delete.

**Automated status:** model + route logic covered by `tests/resume-builder.test.js`
(schema, defaults, template normalization). **Manual status:** the autosave
indicator and duplicate/rename clicks were not exercised in a browser here.

## 6. Live preview (spec §20)

`PDFViewer` renders the same `ResumePdf` document that the download button
generates, with a blob-URL **Open in new tab** fallback and a visible error state
if rendering fails. Text stays selectable; no image rendering path exists.

## 7. Page breaks (spec §23)

- 1 page: all five templates + US Letter + Times Roman variants.
- 3 pages: `sample-long-three-page.pdf` (10 experience entries × 6 bullets,
  8 projects × 3 bullets).
- Entries use `wrap={false}` so an experience/project block is never cut in half;
  headings use `minPresenceAhead`.
- No blank pages and no clipped text (per-page character counts above).
